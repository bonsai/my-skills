# dev-recap — セッション振り返り保存

作業セッションの状態・完了・次の一手を記録して次回に引き継ぐ。

## 発動
- 「save recap」「recapして」「振り返り保存」「状態を引き継ぎ」

## 手順
1. 保存先 docs/recap.md(プロジェクト指定)を確認(他ストリームが更新していれば上書き注意)
2. 構成:
   - 状態(次回の出発点・方針)
   - 今セッションの完了(証拠: commit/URL)
   - ブロッカー・保留
   - 次の一手(優先順)
   - 数量メモ(テスト数・build 等)
3. commit して push(git pull を先に行い衝突を避ける)

## 規約
- 「完了」には証拠(commit hash・動作確認)を添える。未検証は「暫定」明記
- 他セッションが recap を上書きしていたら、新しい内容を土台に現在分を追記
