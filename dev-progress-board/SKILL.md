# dev-progress-board — 進捗の色分け確認

作業の状態を色分けして提示する(kanban 的確認)。

## 発動
- 「進捗確認」「色分けして」「状況一覧」

## 手順
1. 状態ソースを読む: issue/kanban/todo(プロジェクトで指定の docs)
2. 状態を5分類に分ける:
   - 完了(green) / 判断待ち・進行中(amber) / 委譲中(cyan) / 未着手(gray) / ブロック(red)
3. ANSI 色付きで出力(短く1行/分類):
   - GRN=$'\e[32m' AMB=$'\e[33m' RED=$'\e[31m' CYN=$'\e[36m' GRY=$'\e[90m' RST=$'\e[0m'
4. ブロックがある場合は理由と解除条件を併記
5. 最後に「次の1アクション候補」を3つ以内提示

## 規約
- 出力は分類ごと1行に要約。詳細は docs 参照を促す
- 状態は独自判断でなく docs の記号([x]/[~]/[ ]/[!])から読む
