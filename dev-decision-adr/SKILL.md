# dev-decision-adr — 意思決定を ADR 化する

未確定の決定を「選択肢提示→採用→ADR」の形で記録する。

## 発動
- 「decision-options」「ADR化して」「判断材料を文書化」「どう分けるべき」

## 手順
1. decision 文書(プロジェクト指定のパス、例 docs/decision-options.md)に項目を追加:
   状態/関連issue/文脈/判断ポイント(数と内容)/選択肢(強み弱み・数量)/推奨/回答案/採用後ADR候補
2. 判断量(ポイント数・所要分)と実装量(行・token目安)を併記し、1行で決めさせない
3. 人間の回答を受領 → 該当 ADR を adr.md へ追記(新規上、状態[x]、日付・根拠)
4. issue/状態文書を [x] 化し、関連実装タスクへ接続

## 規約
- ADR は「決定と理由」のみ。詳細検討は decision 文書や spec に残す
- 保留は [ ] のまま明示。勝手に採用としない
