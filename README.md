# my-skills

Self-made skills for opencode + pi harnesses.

## layout

Flat list of skills directly installable under the harness skills directory.

## install

```bash
# opencode
ln -s ~/repos/my-skills/* ~/.opencode/skills/

# pi
ln -s ~/repos/my-skills/* ~/.agents/skills/
```
