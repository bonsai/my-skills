# dev-sprint-10 — 10分スプリント(会議+実装)

小さく刻んで確実に進めるループ。1スプリント=10分会議+10分実装で1件のみ。

## 発動
- 「スプリントで」「10分会議10分実装」「1件ずつ」

## 手順
1. 会議(10分): 対象を1件に絞る。議事要旨(決定・担当・次候補)を sprint-log へ追記
2. 実装(10分): その1件のみ実装(必要なら TDD スキル)
3. 検証: test/typecheck/build → 反映(preview 等)→ commit
4. 次スプリント候補を1つ明記して停止(追加の自主作業はしない)

## 規約
- 1スプリント=成果物1つ。会議で2件以上出たら次スプリントへ持ち越し
- 検証不可(実機等)は「人間確認」として Q に積む
